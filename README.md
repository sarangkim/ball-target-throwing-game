# 공던지기 타겟 챌린지

사진 속 타겟 게임을 웹으로 옮긴 2인용 공던지기 게임입니다. 공을 손으로 잡은 상태에서 뒤로 당겼다가 놓으면 과녁으로 날아가고, 각 플레이어가 5개씩 던진 합산 점수로 승패를 가립니다.

## 포함된 기능

- 드래그 기반 공 던지기
- 플레이어 1 대 강화된 컴퓨터 자동 투구 대전
- Google 로그인 후 방 코드 기반 원격 2인 대전
- 컴퓨터 난이도 선택
- 자석 공, 두배 공, 왕공, 안전 공, 폭죽 공 아이템
- 사진 속 원형 점수판 스타일의 과녁
- 3판 2승 라운드제와 플레이어별 3구 점수 합산
- 별, 티켓, 콤보, 랜덤 미션 보상
- 뒤처진 플레이어에게 마지막 공 역전 찬스
- 점수별 히트 효과음과 피날레 효과음
- 사용자가 켜는 놀이공원풍 배경 음악
- Firebase 설정 시 Google 로그인 및 온라인 방 코드 기능

## 실행

정적 웹앱이라 별도 빌드가 필요 없습니다. 로컬에서는 간단한 서버로 열면 됩니다.

```powershell
python -m http.server 5173
```

브라우저에서 `http://localhost:5173`을 엽니다.

## Google 로그인과 온라인 대전 설정

1. Firebase 콘솔에서 웹 앱을 만들고 Authentication의 Google 로그인을 켭니다.
2. Firestore Database를 만들고 테스트 모드 또는 적절한 보안 규칙을 설정합니다.
3. `firebase-config.js`의 값을 Firebase 웹 앱 설정값으로 교체합니다.
4. GitHub Pages 배포 도메인을 Firebase Authentication의 승인된 도메인에 추가합니다.

온라인 방 데이터는 Firestore의 `ball-target-rooms` 컬렉션에 저장됩니다.

## 온라인 대전 방식

1. 두 사람이 모두 Google 로그인합니다.
2. 한 사람이 `방 만들기`를 누릅니다.
3. 생성된 초대 링크를 상대에게 보냅니다.
4. 상대는 링크를 열고 로그인한 뒤 `입장`을 누릅니다.
5. 방장은 플레이어 1, 입장한 사람은 플레이어 2가 되어 번갈아 던집니다.
